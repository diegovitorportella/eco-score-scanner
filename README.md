# EcoScore Scanner - ODS 12

## 📝 Visão Geral
Este projeto foi desenvolvido para a disciplina de Engenharia de Software e visa promover o consumo consciente, auxiliando usuários a identificarem o impacto ambiental de produtos através de um sistema de pontuação (score) de sustentabilidade.

## 🎯 Objetivo (ODS 12)
Abordar a **Produção e Consumo Responsáveis**, combatendo a falta de transparência sobre a pegada ecológica de produtos de consumo diário.

## 🚀 A Solução
Um sistema Web Full-stack que permite a consulta de produtos, processa critérios de sustentabilidade no backend (como materiais de embalagem e logística) e apresenta um feedback visual e educativo ao consumidor.

## 🛠 Tech Stack
- **Frontend:** React (Vite) + CSS
- **Backend:** Node.js + Express
- **Banco de Dados:** PostgreSQL (via Docker) + Prisma ORM
